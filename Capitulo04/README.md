# Consolidación del expediente técnico del proyecto en Word y generación automatizada de la presentación ejecutiva final del diseño para el comité.

### Duración Estimada
60 minutos

### Descripción de la Actividad
En este laboratorio práctico, asumirás el rol de Líder de Innovación y Desarrollo de Producto en Cerámicas del Norte. Utilizando Microsoft 365 Copilot Chat, estructurarás la documentación técnica completa de la nueva colección de recubrimientos porcelánicos de gran formato para pisos y muros. Procesarás fichas técnicas, generarás listas de insumos en tabla para su exportación a Microsoft Excel, redactarás la memoria descriptiva para Microsoft Word, estructurarás la presentación final para Microsoft PowerPoint y crearás un prototipo visual comercial.

---

## Objetivos del Laboratorio
- Consolidar las especificaciones técnicas y fichas de producto de la nueva línea de porcelánicos utilizando Microsoft 365 Copilot Chat.
- Generar cuadros de datos estructurados para su migración directa a Microsoft Excel.
- Redactar la memoria técnica del proyecto adaptada para su documentación en Microsoft Word.
- Formatear el contenido ejecutivo para la creación de diapositivas en Microsoft PowerPoint.
- Prototipar la imagen conceptual de la ficha técnica mediante la generación de imágenes con Copilot.

---

## Prerrequisitos
- Acceso a Microsoft 365 Copilot Chat (Enterprise / Web).

---

### Fase 1: Consolidación de Especificaciones Técnicas

**Herramienta objetivo:** Copilot Chat (Procesamiento Técnico)

Abre Microsoft 365 Copilot Chat e ingresa la siguiente instrucción para consolidar las variables de ingeniería y diseño de la nueva colección de recubrimientos.

```
Actúa como un Ingeniero de Materiales y Desarrollo de Producto especializado en la industria de recubrimientos cerámicos y porcelánicos.

Para la nueva colección de porcelánicos de gran formato de Cerámicas del Norte, consolida un cuerpo de especificaciones técnicas detallado que incluya:
1. Formatos de la pieza (ej. 120x240 cm y 120x120 cm) y espesores para muro (6 mm) y piso (9 mm y 12 mm).
2. Parámetros físicos: Porcentaje de absorción de agua (<0.05%), resistencia a la flexión (N/mm²), escala de dureza Mohs, y nivel de resistencia a la abrasión PEI (Clase V para alto tráfico).
3. Propiedades antideslizantes (coeficiente de fricción DCOF) para aplicaciones en exteriores e interiores húmedos.
4. Cumplimiento de estándares internacionales de sostenibilidad (contenido reciclado pre-consumo, emisiones COV y DAP - Declaración Ambiental de Producto).
```

---

### Fase 2: Cuadro de Rendimientos y Especificación en Tabla

**Herramienta objetivo:** Copilot Chat para estructuración en Microsoft Excel (Tabla Markdown)

Utiliza Copilot Chat para convertir las especificaciones técnicas en una tabla estructurada en Markdown, lista para ser copiada directamente a Microsoft Excel.

```
Con la información técnica procesada en el paso anterior, genera una tabla estructurada en formato de tabla de Markdown estándar para que sea interpretada visualmente por el chat y se pueda copiar directamente a Microsoft Excel.

Requisitos de la tabla:
1. Genera una tabla con bordes claros utilizando la sintaxis estándar de Markdown (| Columna 1 | Columna 2 |).
2. La primera fila debe contener exactamente estos encabezados:
| Modelo / Referencia | Formato (cm) | Espesor (mm) | Aplicación Recomendada (Piso/Muro) | Clasificación PEI / DCOF | % Contenido Reciclado | Rendimiento por Caja (m²) |
3. Completa la tabla estructurando 4 variaciones de la nueva colección de porcelánicos de Cerámicas del Norte.

Fuera de la tabla, en párrafos de texto normal, redacta una nota técnica sobre las recomendaciones de junta de colocación (mm) y adhesivos cerámicos tipo C2TES1 requeridos para la instalación.
```

---

### Fase 3: Redacción de la Memoria Descriptiva del Proyecto

**Herramienta objetivo:** Copilot Chat para documentación en Microsoft Word

Pide a Copilot Chat que integre los aspectos técnicos y conceptuales en un documento formal adaptado para Microsoft Word.

```
Actúa como Director del Departamento de Diseño y Desarrollo de Cerámicas del Norte. Redacta la Memoria Descriptiva Técnica de la nueva colección de porcelánicos sostenibles de gran formato.

El documento debe estar formateado como un informe ejecutivo para Microsoft Word con las siguientes secciones:
1. Antecedentes y Justificación Creativa: Inspiración en piedra natural y arquitectura biofílica.
2. Descripción del Proceso de Fabricación: Tecnología de prensado continuo y reducción de la huella de carbono.
3. Especificaciones Técnicas Generales: Resumen de prestaciones mecánicas, durabilidad y mantenimiento.
4. Guía de Especificación para Arquitectos: Instrucciones paso a paso para incluir este material en pliegos de condiciones y licitaciones de obra pública o comercial.
```

---

### Fase 4: Estructuración del Guion para la Presentación Ejecutiva

**Herramienta objetivo:** Copilot Chat para esquema visual en Microsoft PowerPoint

Utiliza Copilot Chat para transformar el dossier técnico en un esquema estructurado para diapositivas de presentación ante el comité.

```
Con base en la Memoria Descriptiva de la nueva colección de Cerámicas del Norte, estructuraremos la presentación ejecutiva para el comité directivo.Genera el guion completo de contenidos para Microsoft PowerPoint listo para descargar y organizado en 4 diapositivas. Para cada diapositiva especifica:
- Título sugerido de la diapositiva.
- Estructura de contenido en 3 viñetas concisas con datos duros.
- Sugerencia de elemento visual (diagrama, icono o imagen) a incluir en la diapositiva.
Las diapositivas deben cubrir:
1. Portada y propuesta de valor
2. Ficha de rendimiento técnico
3. Certificaciones de sostenibilidad y ventaja competitiva
4. Plan de lanzamiento y volumen de producción inicial.
```

### Fase 5: Redacción de Comunicado y Estrategia de Difusión por Correo

**Herramienta objetivo:** Copilot Chat / Preparación para Microsoft Outlook

Utiliza Copilot Chat para transformar las especificaciones técnicas y los acuerdos de lanzamiento en una serie de correos electrónicos profesionales redactados para su envío directo a través de Microsoft Outlook.

```
Actúa como Director de Comunicación y Marketing de Cerámicas del Norte. Con base en la Memoria Descriptiva y las especificaciones técnicas desarrolladas previamente en este chat, redacta dos plantillas de correo electrónico profesionales listas para enviar desde Microsoft Outlook:

1. Correo Interno (Lanzamiento a Fuerza de Ventas):
   - Asunto: Claro, directo y enfocado en la disponibilidad del nuevo catálogo.
   - Cuerpo: Resumen ejecutivo de la nueva colección de porcelánicos de gran formato, destacando 3 argumentos clave de venta frente a la competencia, fechas de disponibilidad en showrooms y un llamado a la acción para revisar la ficha técnica adjunta.

2. Correo Externo (Comunicado Especial para Arquitectos y Especificadores):
   - Asunto: Atractivo y enfocado en la innovación arquitectónica y sostenibilidad.
   - Cuerpo: Mensaje personalizado invitándolos a conocer la nueva línea, resaltando las propiedades de resistencia PEI, certificación LEED y formatos disponibles (120x240 cm). Incluye una invitación formal a solicitar muestras físicas para sus proyectos en desarrollo.

Asegúrate de que ambos correos mantengan un tono profesional, estructurado en párrafos cortos y con viñetas claras para facilitar su lectura en dispositivos móviles.
```

### Reto Práctico: Adaptación de Especificaciones para Obra Hospitalaria

**Herramienta objetivo:** Copilot Chat (Resolución Autónoma y Modificación Técnica)

**Escenario de Desafío:**
El departamento de compras de un grupo hospitalario nacional está interesado en especificar la colección de Cerámicas del Norte para 15,000 m² de pasillos y salas de cirugía. Sin embargo, la ficha técnica estándar actual no cumple con los protocolos microbiológicos ni con los coeficientes de fricción requeridos por la normativa de salud regional.

**Tu Desafío:**
Debes redactar y ejecutar tu propio prompt en Copilot Chat sin utilizar una plantilla predefinida. Tu instrucción debe ajustar técnicamente la propuesta sin alterar la línea de producción base.

Pistas para construir tu prompt estratégico:
- **Asignación de Rol Complejo:** Indícale a Copilot que actúe como Especialista en Certificaciones y Patología Cerámica.
- **Inyección de Restricciones Específicas:** Pídele que incorpore tratamientos de micro-esmalte antibacteriano (iones de plata) y un incremento en el valor DCOF para zonas de alto tráfico de camillas.
- **Entregable Estructurado:** Exígele que redacte un Anexo de Adenda Técnica para ser adjuntado a la memoria descriptiva de Word y un cuadro comparativo de cumplimiento normativo para Excel.
- **Criterio Comercial:** El prompt debe exigir que se mantenga el margen de precio estipulado sin encarecer la producción en más de un 5%.

---

## Conceptos Clave para Recordar

- Consistencia de Contexto en Copilot Chat: Encadenar requerimientos desde la fase técnica hasta la fase gráfica garantiza que las imágenes e insumos de texto compartan exactamente las mismas especificaciones.
- Formateo Estándar para Exportación: El uso de estructuras de tabla Markdown compatibles facilita la migración de datos numéricos a Microsoft Excel sin perder legibilidad.
- Redacción Técnica Asistida: Traducir pruebas de laboratorio y normativas (Mohs, PEI, DCOF) en argumentos comerciales en Microsoft Word acelera el proceso de especificación arquitectónica.
- Prompts de Imagen Basados en Contexto: Referenciar los datos generados en el chat dentro de la instrucción de Copilot Designer permite crear renders coherentes con la ficha técnica.
